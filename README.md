# STM32F103 OLED 驱动库（SSD1306 / 软件 I2C）

> 本工程的核心是 **OLED 驱动代码**，不是数字时钟项目。  
> `main.c` 中的 24 小时数字时钟只是 **测试例程**，用于验证 OLED 驱动的画点、位图、区域清除、区域反色、刷新等接口是否正常工作。

---

## 1. 项目定位

这是一个基于 **STM32F10x 标准外设库** 的 **128x64 OLED 驱动**。

驱动特点：

- 使用 GPIO 软件模拟 I2C
- 支持 SSD1306 128x64 OLED
- 使用帧缓冲区 `framebuffer[1024]`
- 提供画点、绘制位图、清除区域、区域反色、按索引显示字库、刷新屏幕等接口
- `main.c` 中的时钟程序只是驱动测试代码，实际项目中可以删除或替换

换句话说：

```text
oled.c / oled.h      -> 真正的 OLED 驱动
OLED_Font.c / .h     -> 字库和图标数据
main.c               -> 驱动测试例程，不是驱动本身
My_timer.c           -> 测试用定时器，为时钟例程提供秒计时
